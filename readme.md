# Первоначальная настройка проекта TeamFinder

## 1. Базовая функциональность проекта

TeamFinder — это платформа, на которой разработчики, дизайнеры и другие специалисты смогут находить единомышленников для совместной работы над pet-проектами. У зарегистрированных пользователей будет возможность размещать здесь идеи проектов, находить команду и откликаться на опубликованные предложения.


### 1. **Как должно работать веб-приложение**
   Проект состоит из следующих страниц:
      -Главная,
      -Страница входа,
      -Страница регистрации,
      -Страница пользователя,
      -Страница редактирования профиля,
      -Страница создания и редактирования проекта,
      -Страница проекта,
      -Страница с зарегистрированными пользователями,
      -Страница смены пароля.

## 3. Как развернуть проект.

### 1. **Создайте виртуальное окружение (в папке проекта):**
   ```bash
   python -m venv venv
   ```

   После этого появится папка `venv`, где будут храниться зависимости проекта.

### 2. **Активируйте окружение:**

    - **Windows (PowerShell):**
      ```bash
      source venv/Scripts/activate
      ```

### 3. **Установите зависимости из `requirements.txt`:**
   ```bash
   pip install -r requirements.txt
   ```
   После установки в окружении будут доступны все нужные библиотеки Django-проекта.

### 4. **Запуск PostgreSQL**

Для работы приложения **TeamFinder** используется база данных **PostgreSQL**.

```bash
docker compose up -d
```

Контейнер продолжит работать в фоне. Чтобы его остановить, надо будет ввести

```bash
docker compose down
```

После этого база данных будет доступна по адресу `localhost:5432`. 

### 5. **Запуск Django**

Можно запустить сервер разработки:

```bash
python manage.py runserver
```

Теперь проект доступен по адресу [http://localhost:8000](http://localhost:8000).

## 4. Создание `.env`
| Переменная            | Назначение                                                                                                                                                 |
|-----------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **DJANGO_SECRET_KEY** | Секретный ключ Django, используемый для подписи cookie и токенов.
| **DJANGO_DEBUG**      | Режим отладки.                                                                 |
| **POSTGRES_DB**       | Имя базы данных PostgreSQL, которую будет использовать Django.                                                                                             |
| **POSTGRES_USER**     | Имя пользователя PostgreSQL.                                                                                                                               |
| **POSTGRES_PASSWORD** | Пароль пользователя PostgreSQL.                                                                                                                            |
| **POSTGRES_HOST**     | Адрес сервера БД. В случае локальной разработки localhost.                                                                                                 |
| **POSTGRES_PORT**     | Порт подключения к БД (по умолчанию `5432`).                                                                                                               |
| **TASK_VERSION**      | Номер варианта задания. Используется для определения набора HTML-шаблонов.                                                                          |
